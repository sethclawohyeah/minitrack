## Task Rules

1. **Evan owns this file.** Add tasks from Seth's requests or from self-identified work.
2. **Break down big tasks.** If a task has more than 3 steps, create sub-tasks.
3. **Spawn agents freely.** If a sub-task benefits from a specialized agent, create one.
4. **Priority order:** high > med > low. Within the same priority, oldest first.
5. **Blocked tasks:** Note what is blocking them. If blocked on Seth, send one notification and move to other work.
6. **Completed tasks:** Check them off, add a one-line outcome note, move to Completed.
7. **Stale tasks:** If a task has been queued for 7+ days with no activity, flag it for Seth.
